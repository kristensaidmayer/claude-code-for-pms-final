# Review checklist

Run the same four checks on any brief, every time. Read the whole brief first, then check each point against what the text actually says, not what it probably means.

## The four checks

1. **Owner named.** The brief names a specific person or team who owns it (the decision, the delivery, or both). "We" or "the team" without a name fails. Note if there are several owners with no clear lead.
2. **Success measure.** The brief says how we'll know it worked: a metric, a target or threshold, and ideally when it will be checked. A metric with no target, or a goal like "improve the experience", fails.
3. **Scope matches.** Compare the scope stated at the start (goals, in/out, what's being asked) with what the end commits to (recommendation, next steps, asks). Flag anything the end adds, drops or quietly changes: new work, a different target, a narrower or wider audience.
4. **Problem before fix.** The problem and its evidence are explained before any solution is proposed. Fail it if the fix appears first, or if the problem section is only a restatement of the fix.

## How to respond

Give a short verdict table, then details:

| Check | Result | Evidence |
|---|---|---|
| Owner named | Pass / Partial / Fail | Quote or point to the section |
| Success measure | Pass / Partial / Fail | ... |
| Scope matches | Pass / Partial / Fail | ... |
| Problem before fix | Pass / Partial / Fail | ... |

- For every Partial or Fail, say what is missing and give one concrete suggested fix (a sentence the author could add or change).
- Quote the brief briefly or cite the section heading so the author can find the spot.
- End with one line: ready to go further, or not yet, and the single most important thing to change.

## Rules

- Review only. Do not rewrite the brief or edit the file unless asked.
- Do not add checks of your own. If something else looks wrong (a factual or numbers issue, say), mention it after the verdict as an "Also noticed", clearly separate from the four checks.
- If no brief is specified, ask which file or text to review.
